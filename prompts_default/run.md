Actuá como orquestador del AIthon y dirigí este run de trabajo para construir un MVP.

Vamos a trabajar todo en este mismo chat.

Usá estos agentes cuando convenga:
- producto-problema
- frontend-ux-designer
- constructor-tecnico
- debugger, solo si algo falla
- ui-polish-reviewer
- pitch-demo

Objetivo:
Construir un MVP demostrable para resolver una problemática fueguina con IA.

Regla principal:
No queremos un proyecto perfecto. Queremos una demo clara, funcional y presentable.

Flujo obligatorio:
1. Producto-problema:
   - Elegir o confirmar una problemática concreta.
   - Definir usuario principal.
   - Definir dolor concreto.
   - Definir solución.
   - Definir MVP.
   - Definir qué queda fuera.

2. Frontend-ux-designer:
   - Definir pantallas mínimas.
   - Definir flujo de uso.
   - Definir textos principales.
   - Definir estados necesarios: vacío, cargando, resultado, error.

3. Constructor-tecnico:
   - Construir la demo de la forma más simple posible.
   - Usar datos simulados realistas si faltan datos reales.
   - Priorizar que se pueda mostrar funcionando.
   - Evitar dependencias innecesarias.

4. Debugger:
   - Usarlo solo si aparece un error, pantalla rota, build fallido o comportamiento inesperado.
   - Buscar el fix mínimo viable.
   - No hacer refactors grandes.

5. Ui-polish-reviewer:
   - Pulir la interfaz.
   - Mejorar jerarquía visual, espaciado, contraste, botones, responsive y claridad.
   - Priorizar cambios visibles para la demo.

6. Pitch-demo:
   - Crear pitch de 3 minutos.
   - Crear guion de demo de 90 segundos.
   - Explicar problema, solución, impacto y próximo paso.

Reglas de trabajo:
- Si falta información, hacé supuestos razonables y marcarlos.
- No usar datos privados o sensibles.
- No frenar por investigación extensa.
- Cada fase debe terminar con una salida concreta.
- Antes de construir, confirmá el MVP en una frase.
- Si hay que elegir entre lindo y funcional, primero funcional; después pulido.
- Si hay que elegir entre completo y demostrable, elegí demostrable.

Proponeme 5 problemáticas fueguinas viables para resolver con un MVP de IA hoy.
Rankealas por:
- impacto
- factibilidad
- claridad para jurado
- facilidad de demo

Después recomendá una sola para avanzar.
